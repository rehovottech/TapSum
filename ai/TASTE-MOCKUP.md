# Taste Skill — Creative UI Exploration Mode

Read and follow the installed Taste Skill (`design-taste-frontend`) instructions.

## Objective

I do NOT want a minor redesign of the existing screen.

I want you to act as a senior UI/UX designer and explore genuinely different design concepts for my existing project.

Technology: Ionic React + Phaser 3 + Capacitor.

## Phase 1 — Analyze, but do not imitate

Inspect the existing screen to understand:
- Its purpose and user needs
- Existing functionality and technical constraints
- Required content, branding assets, and interactions

Use this information to understand the problem, NOT to reproduce the current layout.

Do not use the current screen's layout, component arrangement, visual hierarchy, or styling as the default starting point.

## Phase 2 — Develop 4 distinctly different design concepts

Create four alternative design plans. Each must have a different visual direction and layout strategy.

Explore different approaches such as:

1. Editorial / Swiss design — bold typography, strong grid, deliberate whitespace, asymmetric composition.
2. Playful / expressive — vibrant colours, expressive shapes, illustrations, energetic visual hierarchy.
3. Modern / premium — restrained palette, refined typography, sophisticated spacing, subtle depth.
4. Experimental / unconventional — unexpected composition, distinctive navigation, creative card arrangements, unusual but usable interactions.

These are examples, not mandatory templates. Choose concepts appropriate to the actual screen and its audience.

For EACH concept, specify:
- Concept name and design philosophy
- Colour palette with HEX values
- Typography direction
- Layout and component arrangement
- Navigation and interaction ideas
- How it differs from the existing design
- Advantages, limitations, and suitability for the audience

## Phase 3 — Enforce real visual diversity

The four concepts must NOT be the same layout with different colours.

At least these aspects must vary meaningfully:
- Page composition and layout
- Information hierarchy
- Component placement and proportions
- Navigation approach where appropriate
- Typography and visual language
- Use of imagery, illustration, shapes, or whitespace

Avoid automatically preserving the current header, card layout, button placement, and section order.

Keep only the functional requirements that the product actually needs.

## Phase 4 — Create visual mockups

Create four separate, reviewable mockups in an isolated design-preview folder.

Each mockup must demonstrate its proposed design rather than merely describe it in text.

Make the mockups easy to compare in a browser. Use realistic content and the actual project context.

Do not modify production components, styles, routes, game scenes, or business logic.

## Phase 5 — Stop for review

Present all four concepts and explain their key differences.

Do not select a winner on my behalf.
Do not implement any concept in the production application.
Wait for me to choose a direction or request a combination of ideas.

The priority is creative exploration and meaningful design alternatives, not preserving the existing appearance.
